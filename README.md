## Overview

DevTech V2 is the second iteration of my personal portfolio. It’s been redesigned from the ground up for a cleaner, faster, and more intuitive experience—while still showcasing interactive 3D touches powered by Three.js. Whether you’re here to browse projects, read my blog, or peek at the code, everything should feel seamless.

---

## Features

- **Sleek, responsive design**  
- **Three.js integrations** for engaging 3D effects  
- **Open source**—all code is on GitHub  
- **Mobile‑first** layout  
- **Fast load times** and optimized assets  

---

## Tech Stack

- **Framework:** React + Vite  
- **3D Library:** Three.js  
- **Styling:** Tailwind CSS
